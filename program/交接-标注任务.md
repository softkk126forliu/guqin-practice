## 2. 三个致命陷阱（务必先读，否则会重蹈覆辙）

### 陷阱一：不要用录音一致率评判八度

`audio_score_check.py` 的 `aud_pitch` 取的是同音级**最强**的分音，
在泛音音与空弦低音区必然取到泛音而非基频：

```
C2(36) 的 2 次泛音是 C3(48)，D2(38) 的 3 次泛音是 D4(62)
60.51  C2:4.7  C3:4.3  E3:4.2    ← C2 比 C3 还强，基频确实在
```

工具已加 `aud_base`（该音级**出现过的最低**八度 = 基频优先），
八度判定按音色分基准：泛音用最强八度、散按用基频。
**报告里的「八度判定」列才是可用的。**

### 陷阱二：简谱点标记的语义不是「相对基准区」

之前把 `d1`（下方点）定成基准区 `[48,59]`，是**从页面值反推的循环论证**。
正确：点/线表示**相对简谱默认区的八度偏移**，一个八度一档。

### 陷阱三：AI 视觉读减字谱徽位不可靠

减字谱的字位与简谱音**不是一一对应**（字位含「吟猱」装饰与「舟作」等文字说明，
程序检测的减字谱 x 与简谱音 x 明显错位）。

**不要尝试让 AI 直接读徽位。** 徽位改用录音基频反推（见第 4 节），
人只复核异常点。

### 怎么读 marks 图

- **红色数字** = 音序号，对应 spec 里该排 `notes[]` 的下标（1 起）
- **蓝色数字** = spec 里该音的音级（如 `3/4` 表示撮）。**用它交叉验证你的读数**
- **紧贴简谱数字下方的直线** = **下加线**，条数 = 减八度数（0 条 = 默认区）
- **数字上方的 ○○** = 泛音（青城用两个圈）

### 判读陷阱（实测踩过的，按重要性排序）

| # | 陷阱 | 正确做法 |
|---|---|---|
| 一 | 相邻数字的下加线**连成一片**，数"有几条平行线"会错 | 按**每个数字下方各有几条**理解。一组「6 1」共用一条线 = 两个音各一条 |
| 二 | **扫描拖影**会伪装成第二条线（下面那条有弯曲、粗细不匀）| 真下加线**笔直、平行、等宽**。有弯曲/粗细不匀的是拖影，只算一条 |
| 三 | 数字后的**附点**（如「5.」）是时值记号，不是八度 | 忽略附点 |
| 四 | 叠写的**上下顺序**容易读反（「3/4」读成「4/5」）| ≥3 倍放大读，并对照蓝色音级标注 |
| 五 | `note.x` 与谱面实际数字位置**有偏差**（撮/叠写处尤甚），序号可能不在数字正上方 | **一律按红字序号的先后顺序读**，别按"序号落在哪个数字上"猜；每读一个就用蓝色音级核对 |

## 4. 第二步：读出下加线条数，写进 spec

### 目标字段

给每个**非泛音**音增加 `oct_shift` 字段：

```json
{"p": "6", "oct_shift": -1, "harm": false, "x": 27.83, "w": 3.0, "d": 1}
```

- `oct_shift`：相对简谱默认区的八度偏移，**0 / -1**
  - `0` = 无下加线 = 中音区 `[48,59]`
  - `-1` = 一条下加线 = 低音区 `[36,47]`
- **泛音音不加这个字段** —— 泛音发声在徽位上，音高由**徽位**决定，下加线不适用
- `hui`（徽位）：**本轮先不填**（见第 9 节）

> **⚠️ `oct_shift` 定的是「音级区」，不是绝对音高。**
> 低音区 + 音级只能确定**空弦**时的音高（如「1」→ 三弦空弦 C2）；
> 若该音是按音或泛音，真实音高 = 弦空弦音高 + 徽位音程，仍需第 9 节的步骤。
> **不要因为填了 `oct_shift` 就认为音高已确定。**

### 模板已配套支持

模板与检查脚本已加 `octZone()`（本次交接 PR 一并提供）：

```javascript
const octZone = (shift) => {
  if (shift === null || shift === undefined) return null;
  const k = shift | 0;
  return [48 + k * 12, 59 + k * 12];
};
// 有 dot 用 dotZone；否则非泛音音用 octZone；都没有才回落贪心
```

`guqin_page.py` 的 `build_cells_and_rows()` 与 `audio_score_check.py` 的 `load_score()`
都已透传 `oct_shift`。**改了 spec 却没重跑 build，页面不会有变化**。

### 简谱默认区是什么

| 谱 | 定弦 | 默认区（oct_shift=0） | 低音区（oct_shift=-1）|
|---|---|---|---|
| 春风 | bB 调 | 中音区 `[48,59]` | 低音区 `[36,47]` |
| 青城 | 1=C 正调 | 中音区 `[48,59]` | 低音区 `[36,47]` |

工尺谱的低音区（合四一）对应一二三弦的空弦音高，
故青城低区的「1」= 三弦空弦 C2(36)、「2」= 四弦空弦 D2(38)。

## 9. 徽位怎么补（下一阶段）

工具已经能给出**录音基频**（`aud_base`）。
算法：已知 `oct_shift` + 录音基频 → 反推弦与徽位 → 填进 spec。

```
页面发声 与 aud_base 相差 8 度 → 规划值应该是 base + 12（或 -12）
规划值落在 [弦的空弦音高, 下一弦的空弦音高) 区间 → 确定弦
规划值 - 空弦音高 = 徽位音程 → 查表得徽位
```

徽位音程表（半音，相对空弦）：
`一徽5 二徽7 三徽10 四徽12 五徽14 六徽17 七徽19 八徽24 九徽26 十徽28 十一徽30 十二徽31 十三徽32`

> 徽位需要人工复核几处边界（八度处的十二/十三徽），别全信自动推算。
