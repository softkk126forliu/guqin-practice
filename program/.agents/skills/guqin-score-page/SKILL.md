# 古琴跟谱页面生成（2800px SDF 超清无损版）

流程：**你（看图的模型）负责写 `spec.json` 并借助标尺图精准校准每个音的 `[x, w]`**；曲面展平、裁切、去彩笔/荧光笔批注、2800px 有符号距离场（SDF）轮廓重建、16 阶无损 PNG 内嵌、音高换算与单文件 HTML 生成全部由 `scripts/guqin_page.py` 完成。
- 脚本：`scripts/guqin_page.py`（需要 Python + Pillow + numpy + scipy）
- 模板：`templates/page.template.html`
- 原版备份：`scripts/guqin_page.py.bak`、`templates/page.template.html.bak`

## 步骤（每一步都要看输出图再往下走）

1. **读谱，写 `spec.json` 骨架**：
   - 确定曲名 `title`、副标题 `subtitle`、主音 `tonic`（如 `1=♭B` → `"tonic":"bB"`）、行数（谱上每一排简谱+减字谱为一行）。
   - 若书页有明显透视倾斜或书脊弯曲，可在顶层配置 `x_knots`（横向采样列比例，如 `[0.0, 0.08, 0.20, 0.50, 0.88, 1.0]`）和 `y_rows_at_knots`（每排在各横向位置处的纵向中心比例），脚本会先做二维分段线性曲面展平。
   - 每排 `box` 用展平后照片的比例坐标 `[x0, y0, x1, y1]`（0~1），从该排简谱上方（含倚音/泛音圈）到减字谱最底端下方，左右留出拍号与收尾小节线。
2. `python scripts/guqin_page.py rows spec.json` → 看 `out/rows_preview.jpg`，检查红框是否把每一排完整框住且不压到相邻排。
3. `python scripts/guqin_page.py clean spec.json` → 看 `out/row_N.png`（2800px 宽）：
   - 红/橙/蓝彩笔批注会自动去除；
   - 若某排有**黄绿荧光笔涂抹**（如《春风》第 4 排），给该排加 `"highlighter": true`（自动切换 `max(R, G)` 通道让荧光底色隐形）；
   - 若行首拍号旁有深色笔迹紧贴，可加 `"protect_left": 0.09` 保护行首拍号；
   - 铅笔字或远离谱字的黑色手写批注，用行内比例 `"erase": [[x0, y0, x1, y1], ...]` 或顶层全局比例 `"erases": [[x0, y0, x1, y1], ...]` 抹除。
4. `python scripts/guqin_page.py ruler spec.json` → 生成带 **1% 蓝刻度与 5% 红线**的标尺图 `out/ruler_rows.jpg`：
   - 对照标尺图读取每个音（含左上角前倚音、上方简谱、下方完整减字谱左右边界）的左边缘百分比 `x` 和宽度百分比 `w`。
   - 逐音填入 `notes`：
     - `p`：简谱数字数组（如 `["6", "3"]`）或斜杠字符串（如 `"6/3"`）；休止符写 `"rest": true` 或 `"p": "0"`。
     - `x`：该音方框**左边缘**在行宽中的百分比。
     - `w`：该音方框**宽度**在行宽中的百分比（带前倚音或左右结构较宽的减字谱应适当加宽至 `4.0`~`9.2`，确保整个减字谱被完整框住）。
     - `d`：时值（四分音符=`1`，八分=`0.5`，十六分=`0.25`，附点四分=`1.5`，二分=`2`，三分=`3`）。
     - `harm`：是否为泛音（可在行级设 `"harm": true` 或在单音设 `"harm": true`，模拟弹奏会自动切换高八度清亮泛音音色）。
5. `python scripts/guqin_page.py check spec.json` → 看 `out/check_all.jpg`（及 `out/check_N.jpg`）：
   - 检查每个红框是否完整包住该音的简谱（含倚音）与整个减字谱，确认无漏音、无偏框。
6. `python scripts/guqin_page.py build spec.json` → 生成最终单文件 `古琴跟谱 · 曲名.html`（内嵌 2800px 16 阶无损 PNG，无 JPEG 噪点）。

## `spec.json` 示例

```json
{
  "title": "春风（第一页）",
  "subtitle": "许国华、龚一 曲 · 1 = ♭B 紧五弦定弦（2 3 5 6 1 2 3） · 2800px 无损矢量级超清修复版",
  "photo": "IMG_0963.jpeg",
  "tonic": "bB",
  "out": "out_cf_agron_my",
  "html": "古琴跟谱 · 春风_agron_my.html",
  "rows": [
    {
      "box": [0.058, 0.180, 0.865, 0.295],
      "bpm": 56,
      "harm": true,
      "notes": [
        {"p": "6", "x": 5.0, "w": 6.2, "d": 2},
        {"p": "3", "x": 15.2, "w": 6.8, "d": 2},
        {"p": "6/3", "x": 28.0, "w": 5.0, "d": 1},
        {"p": "7/3", "x": 35.2, "w": 4.6, "d": 3}
      ]
    }
  ]
}
```

## 生成页面核心特性
- **2800px SDF 超清行图 + 16 阶无损 PNG 内嵌**：自动识别黑白扫描谱（4x SDF + 双减时线粘连修复）与实拍彩笔批注书页（曲面展平 + 去彩笔/荧光笔 + 2x SDF），笔画边缘平滑锐利、密集减字笔画不粘连。
- **顶部 HUD 领奏卡 + 2800px 1:1 局部放大镜**：实时显示当前音简谱、音名、泛音/散按技法与原谱超清局部特写。
- **干净谱面高亮规则**：已弹过的音无灰色底影（`.mk.done` 透明）；当前音以清爽朱砂红框高亮，不显示拍内进度条，避免视觉与主线程动画干扰。
- **双模式听音跟谱 + 双音色物理建模合成**：支持「智能伴随（推荐）」与「纯听音推进」，模拟弹奏自动区分泛音（清亮晶莹）与散按音（浑厚木质共鸣）。
- **过程文件留存规则**：
  - **模板目录（`program/模板/`）**：直接运行 `python scripts/guqin_page.py build spec.json` 在内存中完成超清重建并输出 HTML，**不保存 `out/` 过程切图文件**。
  - **新加入的曲谱目录（如 `program/春风/` 等）**：**必须保留** `spec.json` 及 `out_*` 过程文件（2800px 行图、1% 标尺图 `ruler_rows.jpg`、对位校验图 `check_all.jpg`），方便后续微调单音框宽、位置或时值并秒级重建。
