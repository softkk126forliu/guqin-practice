## 四、关键约束（容易踩的）

### 4.1 数据层

- **spec 里 `oct_shift` 是谱面事实**，`null` 表示未标注（页面会退化成贪心猜音）。
  **「非泛音音的 `oct_shift` 为 `null`」是唯一的问题信号**，不是「0」。
- `effMidiOf`：泛音 = 原音 + 12（高八度）。**这是简化**，真实古琴按徽位决定（见 issue #36 Q7）。
- 改 spec 后**必须重跑 build**：
  ```bash
  cd program && python .agents/skills/guqin-score-page/scripts/guqin_page.py build 模板/baisuzhen-spec.json
  ```
  产物应与提交一致（`git diff` 为空）。

### 4.2 校验三件套

```bash
cd program
# 1. build 可复现
python .agents/skills/guqin-score-page/scripts/guqin_page.py build 模板/baisuzhen-spec.json
# 2. 模板↔检查脚本对账
python .agents/skills/guqin-audio-check/scripts/check_sync.py --page "模板/agron模板 · 青城山下白素贞.html"
# 3. 标注合法性
python .agents/skills/guqin-audio-check/scripts/verify_annotations.py --spec 模板/baisuzhen-spec.json --page "模板/agron模板 · 青城山下白素贞.html"
```

### 4.3 页面层

- **`#hud` 在手机上是 grid 不是 flex**（`grid-template-columns: 112px minmax(0,1fr)`）——
  改 `flex-direction` 无效。
- **`#lensCanvas` 有三处 CSS 规则**（基础 / 手机媒体查询 / 横屏媒体查询）——
  只改基础规则在手机上完全无效。
- **改 CSS 后必须重跑 `drawLens()`** —— canvas 内部分辨率是 JS 显式设置的，
  不随 CSS 尺寸更新。**只改 CSS 不重绘，字不会变大。**
- 页面 AudioContext 实际采样率是 **48000**（不是 44100）。
  **离线渲染时必须从 `ensureAudio().sampleRate` 读**，否则音高会偏。

### 4.4 合成器层

- Karplus-Strong 的衰减系数**必须按「延迟线周期」定义**，不能乘在每个采样上
  （PR #38 修的就是这个 —— 每秒衰减 1e-54 ~ 1e-104，数学上瞬间归零）。
- 分数延迟固定半采样，让谐振系数恒定。
  （原实现取 `fs/f` 的小数部分 → 谐振系数在 0.123~0.997 乱跳。）

### 4.5 提交规范

见 `README.md` 的「每个功能」一节：**功能分支 → PR → Copilot review → Squash merge → 删分支**。
不要直接推 `main`。
