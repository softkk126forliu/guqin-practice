# 古琴谱八度基准重估 —— 减字谱才是权威来源

> 2026-11-21。本文推翻 `谱面八度点规则.md` 中基于简谱点标记的部分结论，
> 并指出**检查工具的一个系统性判定缺陷**。
> 关联 issue #10。

---

## 1. 起因

方案 A（spec 携带简谱点标记 `dot`）落地后，谱面基准显示 61/61 完全吻合。
但**人工复核排 4 音 13 时发现数据自相矛盾**：

```
排4 音11 「2」   页面 C3     录音 C3
排4 音12 「2+5」 页面 C3+F3  录音 C2      ← 同一个「2」，录音给了两个答案
排4 音13 「2+5」 页面 C3+F3  录音 C2
排4 音14 「2」   页面 C3     录音 C2
排4 音15 「2+5」 页面 C3+F3  录音 C3
排4 音16 「3」   页面 D3     录音 D4
```

录音在排 4 散按段自相矛盾（音 11/15 报 C3，音 12/13/14 报 C2），
说明**该段的录音八度判定不可靠**。

## 2. 减字谱给出的答案

排 4 减字谱（`row_4.png` 的 y 294–463 行）逐段判读：

```
泛音段（音1-10）  苟 攀【七】 勾 七 罨 …「从『舟作」   ← 有徽位「七」
散按段（音11-19） 苟 罨 勺 苟 罨 勾 秤 勾              ← 一个徽位都没有
```

**减字谱规则：无徽位 = 弹空弦。**

bB 调古琴空弦（正调降大二度）：

| 弦 | 一 | 二 | 三 | 四 | 五 | 六 | 七 |
|---|---|---|---|---|---|---|---|
| 空弦 | Bb1(34) | C2(36) | D2(38) | Eb2(39) | F2(41) | G2(43) | A2(45) |
| 简谱音级 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

**七个音级与七根弦一一对应** —— 这正是古琴谱「以弦定音级」的传统。

排 4 散按段的简谱是「2」「3」「5」「6」，全部落在空弦音里：

| 位置 | 简谱 | 弦 | 实际音高 | 页面给了 | 判定 |
|---|---|---|---|---|---|
| 音11 | 2 | 二弦 | **C2 = 36** | C3 = 48 | ❌ 高八度 |
| 音12/13 | 2+5 | 二+五弦 | **C2 + F2 = 36+41** | C3+F3 = 48+53 | ❌ 高八度 |
| 音14 | 2 | 二弦 | **C2 = 36** | C3 = 48 | ❌ 高八度 |
| 音16 | 3 | 三弦 | **D2 = 38** | D3 = 50 | ❌ 高八度 |
| 音17-19 | 3+6 | 三+六弦 | **D2 + G2 = 38+43** | D3+G3 = 50+55 | ❌ 高八度 |

## 3. 工具的判定缺陷（这是所有误判的根源）

`audio_score_check.py` 的 `aud_pitch`：

```python
aud_cands = [m for m in range(48 if c["harm"] else 36, 80) if m % 12 == exp[0]]
aud_m = max(aud_cands, key=lambda m: Pm[m - MIDI_LO])     # ← 取"最强"八度
```

`max(...)` 取的是同音级中**显著度最高**的八度。在以下两种情形它必然取到泛音而非基频：

- **泛音音**：基频弱、高次分音强 → 报高八度
- **空弦低音**：C2(36) 的 2 次泛音是 C3(48)、D2(38) 的 3 次泛音是 D4(62) → 报高八度

实测（起音窗口内逐帧显著度）：

```
60.51  C2:4.7  C3:4.3  E3:4.2     ← C2 比 C3 还强，基频确实在
60.61  A4:5.4  C3:5.3  C2:5.2
60.70  A4:4.5  C2:4.5  D♭6:4.4
```

**基频存在且很强，但 `aud_pitch` 取到了更强的泛音。**

### 改进判定的实测

改为「取该音级在窗口内出现的**最低**八度」（基频优先），全曲重算：

```
排5 音1-14「6」→ 最低 G2   (11 个音全部一致)
排5「7」→ A2    排5「1」→ Bb2    排5「5」→ F2
排4 音11-15 → C2    排4 音16-19 → D2
```

**全部落在 bB 调空弦区 [34,45]**，且同音级高度一致 —— 这个整齐度不可能是噪声。

结论：**页面在排 4、5 的低音区段普遍高了八度。**

（之前"最强八度"报 G4/D4，曾让我误判为「页面偏低八度」—— 那是泛音误判。）

## 4. 被推翻的结论

| 原结论 | 状态 |
|---|---|
| `d1`（下方点）→ 规划 MIDI ∈ [48,59] | ❌ 错。应为 **[36,47]**（低八度区） |
| 无点标记 → 规划 MIDI ∈ [48,59] | ❌ 未经验证。排 5 同样是无点，但实际在空弦低音区 |
| 「谱面基准 88/88 = 100%」 | ❌ **必须撤回**。d1 的区间是从页面值反推的（循环论证），无点音的区间是推定的 |
| 「录音基准 44/74」 | ⚠️ 该指标本身有系统性偏差（泛音误判），需改进判定后重估 |

**「点标记 → 音区」的映射不自洽**：排 4 与排 5 都是低音段，但页面给排 4 是 C3、给排 5 是 G3，
而两者实际都在空弦区。简谱的点标记不足以还原古琴的绝对音高。

---

## 5. 根本原因

**古琴谱的绝对音高 = 弦的空弦音高 + 徽位音程。**
弦由音级决定（bB 调音级 n ↔ 第 n 弦），徽位由减字谱给出。

简谱对照谱里的点标记只是**编者的辅助标注**，既不完整也不标准
（排 5 有九徽/十徽按音却无点标记，排 4 有低音点却是空弦）。

因此：

> **方案 A 的数据格式设计有缺陷 —— 应该记录「弦 + 徽位」，而不是「点标记」。**

## 6. 后续工作

### 6.1 检查工具（独立可做，收益明确）—— ✅ 已完成

工具已新增基频判定，报告并列输出两列录音音高：

| 列 | 含义 | 判定基准 |
|---|---|---|
| `aud_pitch` | 同音级**最强**的分音 | 泛音音（基频被抑制，发声就是高处的分音）|
| `aud_base` | 同音级**出现过的最低**八度 | 散按音（尤其空弦低音，最强八度必落在泛音上）|

八度判定按音色自动选基准，输出 `八度判定` 列（八度一致 / 页面高N八度 / 页面低N八度 / 音级不符），
summary 增加 `oct_ok` / `oct_bad` / `oct_hist`。

**春风页实测（0–120 秒，96 个可判音）：**

```
八度判定：一致 45 / 偏差 51 / 音级不符 0
偏差分布：页面高1八度 46   页面高2八度 4   页面低1八度 1

按音色分组：
  泛音: 42/50 一致 (84%)     ← 点标记 u1/u2 有效，页面基本对
  散按:  3/46 一致 (6%)      ← 几乎全错，43 个高一个八度
```

**这个分组结果是本轮最重要的产出**：它把「泛音处理」和「散按处理」明确区分开了 ——
泛音段（减字谱有徽位）页面基本正确；散按段（无徽位=空弦，或按音）页面系统性高八度。

同时它也暴露了一个**必须人工标注**的事实：散按音的正确八度取决于徽位，
「点标记」无法表达 —— 排 4 散按段无徽位（空弦，低音区），排 5 标有九徽十徽（按音，中高区），
两者方向相反，不能用一条统一规则修。

### 6.2 spec 数据格式重构

```
现状:  {"p": "6", "dot": "u1"}
建议:  {"p": "6", "string": 6, "hui": null}      ← 空弦
       {"p": "3", "string": 3, "hui": "7"}        ← 三弦七徽
       {"p": "6", "string": 6, "hui": "9"}        ← 六弦九徽
```

模板按 `空弦音高[string] + 徽位音程[hui]` 直接定音高，不再猜。

### 6.3 标注工作量

98 个音需标注「弦 + 徽位」。减字谱与简谱音**不是一一对应**
（减字谱字位含「吟猱」装饰与文字说明，程序检测的 x 与简谱音 x 明显错位），
**AI 视觉读减字谱不可靠**，建议人工标注。
